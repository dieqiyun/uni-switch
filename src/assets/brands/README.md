# Client brand assets

These assets identify the clients supported by uni-switch. The marks belong to their respective owners and are not covered by uni-switch's AGPL license.

- `codex.png`: original light-theme icon from the official Windows package `OpenAI.Codex_26.930.3930.0_x64__2p2nqsd0c76g0`, file `assets/Square44x44Logo.targetsize-256_altform-lightunplated.png`. OpenAI's original image is used unchanged.
- `claude.png`: original Claude mark from the official website, `https://claude.com/icon.png`, retrieved 2026-10-06. Anthropic's original image is used unchanged.

- `zcode.png`: official ZCode website favicon, `https://zcode.z.ai/favicon-192x192.png?v=20260707-transparent`, retrieved 2026-10-10. Original PNG used unchanged.
- `dsh.svg`: official DeepSeek Harness website favicon, `https://www.deepseek.com/harness/favicon.svg`, retrieved 2026-10-10. Original SVG and its light/dark color rules used unchanged.
- `workbuddy.svg`: official WorkBuddy website mark, `https://assets.workbuddy.cn/web/workbuddy/f4728a12fe9cfe5a34da6b2fa827614041c84386/assets/logo.svg`, linked by `https://www.workbuddy.cn/`, retrieved 2026-10-10. Original SVG used unchanged.

Assets are bundled locally; the application does not request logos at runtime.
