# 简洁界面 · 0.5.11

供应商管理采用平铺列表：每行上方显示名称、地址和使用、编辑、删除，下方显示模型、上下文、Fast与余额。行之间仅用分隔线，当前供应商使用浅色背景。去掉首字母头像、供应商外框、重复正常状态说明及“更多”菜单，保留官方客户端Logo和一体化窗口。

模型名称和已启用数量共用一个入口，点击后在该行下方直接展示模型列表。这里可以同步、搜索、勾选、设为默认和调整逐模型上下文。选择保留为草稿，确认后一次写入，取消不保存；不再同时显示默认模型下拉和模型配置按钮。首次同步与新发现的适用模型仍默认全选，主动取消的选择及已有上下文在刷新时保留。

添加、编辑表单按连接字段、模型设置、高级设置排列，使用留白与分隔线。移除重复模型标题和多层卡片边框；模型列表与高级设置固定展开。API协议、认证和Fast使用原生单选按钮，全部选项平铺显示。协议、认证默认自动匹配，Fast保留跟随客户端、开启、关闭三种值；原生键盘方向键可以切换选项。

余额直接显示查询结果与额度类型，刷新按钮独立。信息按钮显示查询时间、上次结果、失败原因等详情，详情在普通列表中展开，不使用下拉菜单或额外卡片。账户余额、密钥额度与订阅额度的原有区分继续保留。

## 配置与保存

- 首次接入仍只需API地址、API Key和一个“添加并使用”按钮。
- 日常切换只需“使用”，编辑和删除直接可见；使用中的供应商删除前仍需先切换或恢复。
- Fast、当前模型上下文、名称与置顶继续在供应商行直接操作。地址、密钥与协议覆盖在编辑中确认。
- Codex每次实际文件写入自动检查并补齐思考强度显示，成功后提示立即重启或稍后重启。Claude桌面与CLI保留各自重启检测。
- 行内模型配置和表单取消不写入；待应用修改、外部冲突与过期快照继续阻止快捷写入。
- 配置目录仅在设置查看、手动修改。无框窗口、托盘与转换服务继续使用原有机制。

## 验证方式

使用隔离数据库、配置目录与模拟供应商在真实Tauri/WebView2窗口运行验收。检查列表和供应商表单无select/details菜单、平铺单选的默认值、余额详情键盘操作、直接编辑入口与关闭后的焦点返回、390px布局以及等效125%/150%/200%缩放。配置流程继续覆盖两协议和三个目标、模型默认全选、85个模型完整写入、取消草稿、Fast自动修复与客户端重启。

原生结果保存到`.qa/ux-flow/results.json`，未执行的检查单独记录。截图位于`docs/screenshots/flat-provider-list-0.5.11.png`、`flat-advanced-form-0.5.11.png`和`inline-model-settings-0.5.11.png`。
