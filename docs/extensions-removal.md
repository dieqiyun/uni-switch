# 扩展与插件功能移除

按产品要求，此版本在代码层面移除第三方扩展，不通过隐藏按钮或运行时开关停用。

- 删除市场、搜索、npm/GitHub/本地包安装和更新入口。
- 删除 Bun/JavaScript 宿主、第三方认证与续期、插件工具和扩展页面/面板/本地服务桥接。
- 删除第三方客户端模块及网关 JavaScript 中间件、路由策略、用量观察器的执行实现。
- 删除侧栏、设置页、添加供应商、推荐、签到及订阅迁移中的扩展管理入口，删除对应管理 API 和 CLI 命令。
- 旧插件列表、认证、包文件及用户供应商数据留在磁盘；不加载、不执行，也不自动安装或迁移。仅保留存量记录所需的数据类型兼容层，执行和修改操作返回明确的不可用错误。
- 网关、供应商 API Key、内置订阅、客户端配置适配、路由、用量、会话、资源库、隐私与备份继续使用静态核心模块。旧 plugins.yml 不再控制它们的启停。仅依赖第三方扩展的订阅接入不再提供。

验证使用临时 HOME、独立 QA 核心和合成凭据，不操作日常客户端。定向 Go 回归覆盖旧插件文件忽略、执行拒绝、管理接口 404、内置页面与目录；浏览器覆盖 Chromium/WebKit 和五种语言，检查旧扩展链接回退、供应商添加、设置与核心页面。全量验证和跨平台产物未完成前不发布。
