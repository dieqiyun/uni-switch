## 已修复的保留功能

- 普通 Codex 历史切换到较长的供应商 id 再切回时，原实现会多出尾部空格。`rewriteCodexProvider` 仅对分页历史使用定长填充，普通历史恢复为只替换供应商 token。原有 `TestMoveCodexProvider` 修改前明确失败，修复后供应商移动、压缩文件、分页偏移、活动线程及恢复相关 15 项测试通过。分页历史仍拒绝放不下的 id，不改动文件。
- 模型缓存文件路径直接复用 `appdir.Cache()`，避免每次调用 `filepath.Dir(CachePath())`。路径分配测试扣除 Windows 读取当前 UTF-16 环境变量的系统成本，仍要求路径构造不增加分配；修改前的实现明确多一次分配。没有缓存环境变量或改变目录变化后的即时读取行为。
