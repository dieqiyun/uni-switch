# 0.5.29 侧栏设置和版本显示修正

日期：2026-11-12（Asia/Shanghai）。此修正属于未发布候选，沿用原有发布门槛。

窗口宽度跨过 1024 CSS 像素时，共享界面保存的旧 `layoutNav` 回调会把设置移入已隐藏的 `.side-foot`。在 1120×775 缩至 1018×704 的隔离窗口中，设置按钮高度从 30 变为 0，复现用户截图中的消失现象。宽度回调现在执行当前的布局函数，包含产品侧栏位置恢复。

15 分钟更新定时器同样保存了旧 `renderUpdateBadge`，没有更新可用时会隐藏产品的版本行。定时器改为执行当前渲染函数。当前版本在启动时、每次检查更新之前立即显示，不等待接口返回。小窗口、大字体下，展开的设置或资源库子菜单可在剩余高度内滚动，固定导航行保持可见。

## 本轮验证

- 旧构建运行新增回归时，明确失败于 `current version is visible while the update request is pending`；初版修正运行新增定时回归时，明确失败于 `periodic update check keeps the current version visible`。最终源码嵌入核心后，侧栏回归 Chromium/WebKit × 五语言共 10 组通过。
- 回归覆盖更新响应挂起、失败与新版本状态、反复跨过宽度断点、760×600 和有效 507×400 视口、深浅主题、点击与 Enter/Space 折叠、子菜单 End/Enter 选项、焦点与滚动保留、底部控件实际命中检测。
- Windows 原生隔离窗口验证 100%→110% 字体跨过断点、150% 字体、设置/版本点击与键盘操作。正式构建另做独立数据目录启动检查。测试没有修改、停止或重启日常程序及客户端配置。
- 产品设置与客户端流程各 10 组、网关设置 2 组通过；前端源码测试 21 项、TypeScript、前端生产构建和来源清单校验通过。
- 额外运行导入的 `nav-timeout`、`text-size`、`update-hide` 三个旧 GUI 测试文件：41 项中 4 项通过、37 项失败。具体包括旧面板缩放假设、设置列表滚动假设、已删除独立 Gateway 导航选择器、旧设置读取夹具超时，以及测试文件自身的短超时检查。没有据此恢复已删除功能或声称 GUI 全量通过。
- 本轮没有重新运行 1128 个导入 GUI 测试文件或完整 Go 回归，也未执行 Linux/macOS 原生构建。此前完整 Go 回归的失败和三平台发布阻塞仍有效，见 `0.5.29-qa.md`。修复本身通过不等于正式发布验收通过。

本机截图和运行结果保存在 `.qa/sidebar-compact-verification.json`、`.qa/sidebar-native-verification.json`、`.qa/sidebar-native-fixed-full.png` 等独立 QA 文件中，不包含在公开源码内。
