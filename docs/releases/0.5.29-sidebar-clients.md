# 0.5.29 客户端侧栏候选验证

本记录属于尚未通过发布验收的 v0.5.29 候选。此前的后端回归失败仍是正式发布阻塞。

客户端列表默认显示前 8 个，点击“查看更多客户端”后侧栏加宽，以两列显示全部 11 个；收起后恢复。客户端列表没有独立滚动区。会话、资源库、设置与版本入口位于底部，设置和资源库的分类放在内容区。高度不超过 720 CSS 像素时使用紧凑客户端行，为底部导航留出空间。极小视口与大字体下，整条侧栏可以滚动，底部入口保持可达。

继续保留上轮设置与版本修复：跨过 1024 CSS 像素时调用当前布局函数，更新请求未返回时立即显示当前版本，15 分钟定时器调用当前版本渲染函数。网关设置模块的名称和说明已补齐简体中文、繁体中文、日语及德语。

本轮已执行：

- 修改前的生产核心运行新侧栏回归，在 `exactly eight clients show by default` 失败，实际为 11 个。补回宽度断点检查后，新布局又在 1018×704 的底部留白断言失败；修正紧凑布局高度后通过。
- 修改后的核心在 Chromium/WebKit × 英语、简中、繁中、日语、德语共 10 组侧栏回归通过，覆盖 1120×880、1018×704、1120×774、760×600，及 507×400 有效大字体视口的底部入口可达性。
- 检查默认 8 个、展开 11 个、鼠标与 Enter/Space 操作、刷新后的焦点与展开状态、设置与资源库分类、深浅主题、名称不换行、版本请求挂起和定时刷新，以及侧栏按钮名称、ARIA 和对比度。
- 11 个客户端的配置流程在两种引擎、五种语言共 10 组通过。
- `TestBuiltinsTranslated` 修改前缺少 8 处模块翻译，补齐后通过。
- 前端源码测试 21 项通过；TypeScript、生产前端构建、Windows Go vet、Rust 隔离测试和 Clippy 通过。

完整 Go 回归仍保留，不以专项通过代替全量结果。最新失败范围和发布状态见 `0.5.29-qa.md`。本机日志、截图及合成配置位于 `.qa`，不进入公开源码。
