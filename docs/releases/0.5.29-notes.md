# uni-switch 0.5.29

本版本为发布候选，尚未公开；必须通过三平台检查和全部产物校验后才能作为正式发行版使用。

- 受管 Codex / ChatGPT 桌面配置强制使用简体中文；旧语言覆盖为 zh-CN。
- uni-switch 的 Codex 供应商固定 requires_openai_auth = true，补齐旧的缺失或 false；仍需可用的 ChatGPT 登录，账号额度、套餐和官方服务端权限继续适用。
- 删除导入源码内置的 Google OAuth 注册信息；Gemini CLI / Antigravity 登录和导入改用数据目录中的私有 `google-oauth.json`，旧账号缺少原始注册信息时需重新登录。
- 显式数据目录使用独立的桌面单实例标识，支持在隔离目录启动候选程序。
- 收录完整源码整合、本产品命名、简化后的客户端与供应商界面、本机网关和 256000 默认上下文。
- 移除第三方扩展市场和执行宿主、跨设备同步和配置包备份、局域网共享和远程管理、请求脱敏规则、外部观测导出、用量报表及路由组。保留普通供应商路由、账号和密钥轮换、备用模型、请求诊断、会话、资源库及客户端原子配置恢复。历史数据不自动删除。

计划提供 Windows x64 安装版／独立程序／便携包、Linux x64 DEB／AppImage、macOS 通用 DMG／app 压缩包、精确对应的 AGPL-3.0-only source.zip、中文指南与 SHA256SUMS。

macOS 最低版本为 12，采用 ad-hoc 签名，未进行 Apple Developer ID 公证；首次打开可能需要在系统隐私与安全设置中允许。Windows 程序未购买代码签名证书。SHA256 校验不等于代码签名或公证。

配置应用后根据客户端提示重新打开客户端。macOS／Linux 自动重启及系统登录启动尚未实现；需要手动重启。真实账号、官方云端功能与第三方模型工具兼容性未作完整验证。

当前验证与阻塞见 docs/releases/0.5.29-qa.md。
