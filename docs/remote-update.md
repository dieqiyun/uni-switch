# 桌面应用更新

v0.5.32 恢复了 Go 核心整合后缺失的桌面更新功能。v0.5.30 和 v0.5.31 的桌面更新接口仅返回当前版本，没有查询 GitHub；需要从本项目发布页手动升级一次。已发布版本及其源代码标签保持不变。

## 检查新版本

侧栏底部的版本行进入「设置 → 关于」。自动检查开启时，程序在启动时及每六小时读取 `https://api.github.com/repos/dieqiyun/uni-switch/releases/latest`；检查失败后十五分钟重试。关于页可关闭自动检查，也可随时点击「检查 GitHub 更新」。检查仅读取稳定版元数据，不下载或安装。忽略 draft、prerelease 及不合法的版本号。

发现较新版本后，侧栏显示「有新版本」。关于页显示最新版本、发布说明、检查时间和错误原因。网络失败保留已知版本信息，可再次检查。所有请求使用应用现有的出站代理选择，不携带供应商密钥或 GitHub 登录令牌。

## 下载与安装

点击「下载更新」会重新读取 GitHub Latest。只有所选版本仍为最新版本时才下载本机对应的安装包。界面显示实际字节数及进度，支持取消、失败重试；下载完毕停在「校验通过」状态，必须另行点击「安装更新」。已下载的包可以取消并清除，下载和检查都不会自动安装。

也可点击「GitHub 下载」，在固定项目的发布页手动下载。

- Windows x64：下载 `_x64-setup.exe`。点击安装后打开 NSIS 安装向导，默认目录为当前桌面程序所在目录，然后退出 uni-switch。完成向导后重新打开程序。便携版也使用完整安装包更新，需要完成向导。
- macOS Intel / Apple Silicon：下载 `_universal.dmg`。点击安装打开磁盘映像，按系统界面替换 Applications 内的 uni-switch，再重新打开。
- Linux x64：普通安装下载 `_amd64.deb`，交给系统安装程序完成安装；运行 AppImage 时下载 `_x86_64.AppImage`，打开下载目录，用户替换原文件、赋予执行权限后再启动。
- 其他架构没有匹配的官方安装包时，显示错误并保留 GitHub 下载入口。

更新不会更改客户端配置或重启 Codex / Claude。Windows 退出 uni-switch 后，其本地网关会停止，重新打开程序后恢复。系统安装和文件替换由用户完成，应用不宣称无人值守安装。

## 下载完整性和边界

发布仓库、Latest API、标签和安装包名称由后端确定，页面只能提交版本号与一次性下载任务标识，不能传入下载 URL、本地路径或安装命令。仅允许 GitHub HTTPS 及其官方发布资源域名重定向。资源须有正数大小，上限 1 GiB，并具备 GitHub `sha256` digest 或发布内 `SHA256SUMS.txt` 的唯一精确文件名条目。

下载验证长度、SHA-256 和 EXE / DMG / DEB / ELF 格式标识。点击安装前再次读取并校验，拒绝缓存被改动及重复使用的任务。这里的信任根是本项目 GitHub 发布权限，哈希不等同于发布者数字签名。

网络检查限时 45 秒，下载无数据一分钟即中止，单次操作最长 30 分钟。取消和错误只清理本次创建的私有下载目录；已交给系统安装程序的包保留。隔离 QA 禁止启动真实安装程序。

## 实现和验证

`backend/internal/desktopupdate` 负责 GitHub 元数据、下载状态、校验和取消；`backend/internal/gui/uni_switch_update.go` 提供受现有 cookie / 同源规则保护的更新 API 与系统安装交接；`assets/uni-switch.js` 提供关于页及侧栏提示。原独立核心的自替换更新器不会处理桌面安装。

回归覆盖启动发现新版本且不下载、GitHub 故障恢复、完整性失败、缓存改动、取消和重试、平台资源匹配、拒绝页面传入 URL / 路径及重复安装。`scripts/qa-source-update.mjs` 在 Chromium / WebKit、五种语言和窄窗口中覆盖检查、进度、取消、重试、显式安装、键盘操作和可访问性。所有测试使用隔离目录和合成凭据。
