# 无框窗口与一体化顶部

0.5.7 移除 Windows 原生标题栏，顶部直接延续侧栏和工作区的背景，不再重复显示应用图标和标题。保留系统阴影与窗口边缘缩放能力。

右上角提供最小化、最大化 / 还原、关闭三个按钮。顶部空白区域、左侧品牌和主标题可拖动窗口；双击这些区域可最大化或还原。刷新、设置和供应商操作仍保持普通按钮交互。

关闭按钮将主窗口隐藏到托盘，保留余额刷新和本机协议转换。可从托盘重新打开；最小化的窗口也会还原。彻底退出请使用托盘菜单的“退出应用…”。浏览器预览不显示桌面窗口按钮。

窗口按钮提供中文辅助名称、键盘焦点和 Enter / 空格操作。弹窗出现时，遮罩覆盖顶部拖动区域及窗口按钮，避免拖动窗口或关闭主窗口干扰尚未确认的表单。弹窗取消与配置写入、重启提示沿用已有规则。

本轮验收使用隔离的测试进程、数据库、WebView2 数据和客户端目录，不关闭用户正在运行的旧版，也不修改用户真实客户端配置。窗口检查由 `scripts/qa-window-chrome.mjs` 和 `scripts/qa-window-native.ps1` 执行，结果保存在 `.qa/ux-flow/window-chrome-results.json`。真实窗口探针核对客户区顶部相对于外框的距离，并验证鼠标拖动、最小化、最大化、双击、隐藏及恢复。Windows 为缩放与阴影可能保留内部标题栏样式标志，不能只凭此标志判断原生标题栏是否显示。恢复测试通过 Windows 窗口 API，托盘菜单的还原逻辑同时通过代码检查和 Rust 编译验证。
