# uni-switch 使用说明

## 安装与升级

从项目 GitHub Releases 下载适合系统的已发布程序，按同版本 `SHA256SUMS.txt` 核对文件。Windows 可选择安装程序或便携包；Linux 提供 DEB 与 AppImage；macOS 提供通用 DMG 与 app 压缩包。

macOS 最低版本为 12。应用采用 ad-hoc 签名，未进行 Apple Developer ID 公证，首次打开可能需要在系统隐私与安全设置中允许。Windows 程序没有购买的代码签名证书。以上签名情况与 SHA256 文件校验是不同的检查。

## 添加账号或 API

在客户端页面选择要配置的应用，添加支持的订阅账号，或新建自定义 API 供应商。API 地址、接口协议、API Key 和实际可用的模型由供应商提供。填写后获取模型列表，选择需要使用的模型，再应用客户端配置。

本地保存的账号不代表该服务授予所有模型或工具权限。真实登录、套餐和额度由对应服务确认。不要把 API Key 发给他人或提交到公开源码。

## 客户端配置

uni-switch 写入客户端原生配置，保留无关设置，并使用原子写入和失败回滚。遇到外部修改时，先查看冲突提示与实际配置。连接或切换模型后，根据客户端提示重新打开客户端；旧会话遇到供应商或签名错误时可新建对话。

受管 Codex / ChatGPT 桌面配置固定为简体中文 `zh-CN`，uni-switch 的供应商固定 `requires_openai_auth = true`，旧语言和旧 `false` 会被替换。没有可用 ChatGPT 登录时可能需要登录；额度耗尽仍可能阻止发送。这个设置不会授予官方云端功能权限，也不保证任意第三方模型支持全部官方工具。

## 本地网关与请求排查

在「设置 → 网关」查看实际地址、运行状态和请求记录。新数据的推理网关默认地址为 `127.0.0.1:18425`；以应用当前显示值为准。管理界面使用独立的随机本机端口。

请求记录可以帮助查看所用供应商、模型、耗时、结果和错误原因。先核对 API 地址、协议、模型 ID、账号额度和供应商返回的错误，再调整配置。普通供应商路由、密钥和账号轮换、备用模型继续保留。

## 数据与功能边界

应用使用独立本地数据目录。客户端原子写入、配置失败回滚和断开恢复继续保留。旧数据不会因为功能移除而自动删除。

当前版本不提供第三方扩展市场和执行宿主、跨设备同步、配置包导入导出与自动备份、局域网共享与远程管理、请求脱敏规则、外部观测导出、用量报表或路由组。会话和资源库仍是独立功能。

## 源码与验证

项目按 AGPL-3.0-only 提供源码；对应发行版标签和 source.zip 应与二进制构建使用的提交一致。开发、来源和三平台发布流程见 [项目主页](../README.md)。当前未发布候选版本的检查结果见仓库中的 `docs/releases/0.5.29-qa.md`。
