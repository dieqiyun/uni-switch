# uni-switch 中文使用指南

uni-switch 在本机管理 AI 供应商、API Key 和客户端模型配置。首次使用先添加供应商，再连接客户端并选择模型。

## 安装与启动

- Windows：运行 `x64-setup.exe` 安装；便携版解压后运行 `uni-switch.exe`。
- Linux：安装 `.deb` 包，或给下载的 `.AppImage` 添加执行权限后运行，例如 `chmod +x uni-switch_*.AppImage`。
- macOS：打开通用 `.dmg`，把应用拖入「应用程序」。发行包使用 ad-hoc 签名，未做 Apple Developer ID 公证；首次打开可能需要在系统设置中确认。

启动后保持 uni-switch 运行，让客户端能够访问本机网关。下载时可以用 `SHA256SUMS.txt` 核对文件；Windows 可使用 PowerShell 的 `Get-FileHash -Algorithm SHA256`。

点击窗口右上角的 × 会将应用隐藏到托盘。要结束应用，请在托盘菜单选择「退出应用…」。有客户端连接时，可以在确认窗口中选择退出、断开连接后退出或取消。如果确认窗口无法操作，一分钟内再次选择托盘的「退出应用…」即可退出。

## 检查和安装更新

v0.5.32 起，默认在启动时和每六小时查询本项目 GitHub 最新稳定版。点击侧栏底部的版本行进入「设置 > 关于」，可以手动检查或关闭自动检查；发现新版后，侧栏显示「有新版本」。

点击「下载更新」后显示实际进度，可取消和重试。安装包通过大小、SHA-256 和格式校验后，再单独点击「安装更新」。Windows 打开安装向导并退出 uni-switch，完成后重新打开；macOS 打开 DMG，由用户替换应用；Linux 打开 DEB 系统安装程序或 AppImage 下载目录。也可通过「GitHub 下载」手动获取安装包。关闭 uni-switch 期间，本地网关暂时停止。

**v0.5.30 / v0.5.31 需要先从 GitHub 发布页手动升级一次**，旧版缺少实际查询更新的客户端代码，无法仅靠远端发布新版本获得提示。

## 添加供应商和 API Key

在供应商页面添加条目，填写供应商名称、API 地址和 API Key。不同协议使用对应的 API 地址；自定义供应商请使用服务商提供的完整地址。获取模型列表后选择需要提供给客户端的模型，再保存。

供应商名称用于区分服务来源，API Key 分组名称用于区分同一供应商的不同权限、套餐或模型列表。

## 同一个供应商添加多个分组

1. 添加供应商时，为第一个 API Key 填写分组名称，例如「普通组」。
2. 编辑这个供应商，点击「添加 API Key 分组」。
3. 填写另一个 Key 和分组名称，例如「高级组」，保存后获取并选择该组的模型。
4. 在客户端选择带有相应分组名称的模型。

每个分组独立读取和保存模型列表。客户端显示为「模型名 · 分组名 · 供应商名」，例如「GPT-5.5 · 高级组 · 我的供应商」。选中分组模型后，请求固定使用该分组的 Key。升级后请重新选择带分组的模型，并重新打开客户端加载模型列表。

更多说明见 [API Key 分组](api-key-groups.md)。

## 连接 Codex、Claude Code 等客户端

在客户端页面找到已安装的软件，连接到 uni-switch 并选择模型。完成后重新打开客户端；如果客户端保留旧列表，请先完全退出，再启动。

Codex 没有 ChatGPT 登录态时可以通过本机 bearer 连接使用供应商模型。应用会根据已知登录态生成对应配置；使用原生订阅账号时仍按该账号自己的登录方式操作。

## 本机网关设置

打开「设置 > Gateway」查看运行状态、地址和连接示例。默认推理地址是 `http://127.0.0.1:18425/v1`，实际地址以应用显示为准。端口和裸模型 ID 等选项位于高级配置中。

网关只接受本机请求。命名网关 Key 可用于本机调用归属、模型范围和限额；撤销或停用后，请更新持有该 Key 的客户端。专用 WSL 适配器使用它自己的本机连接和 Key 配置。

## 常见问题

- 客户端没有新模型：确认对应分组已获取并选择模型、保存成功，然后重新打开客户端。
- 供应商返回认证失败：核对当前分组的 Key、服务地址和套餐权限。不同分组可见的模型可能不同。
- 本机连接失败：确认 uni-switch 正在运行，并使用设置中显示的实际地址和端口。
- 请求内容无效：检查客户端发送的 JSON 和协议。空请求或截断 JSON 会返回结构化错误。
- 查看调用问题：在「设置 > Gateway」展开请求记录，查看模型、供应商和错误信息。
