# 同供应商多个 API Key

添加供应商时可以设置 API Key 分组名称；编辑供应商后点击「添加 API Key 分组」可添加其他 Key。每个分组分别读取和选择可用模型。客户端显示为「模型名 · 分组名 · 供应商名」，选中后固定使用该分组的 Key。更新后请重新选择模型，并重新打开客户端。详见 [API Key 分组](api-key-groups.md)。
