## 蝶祈云提供什么

蝶祈云面向个人、开发者与团队提供 AI API 渠道接入。官网展示的模型生态包括 **GPT、Claude、Gemini 以及国内模型**，应用场景包括科研探索、项目开发与日常模型使用。

官网介绍了三类渠道建设方向：

| 方向 | 介绍 | 使用场景 |
| --- | --- | --- |
| GPT 真官 Key 科研探索 | 持续探索和打磨 GPT 模型接入，并关注渠道来源与使用体验。 | 希望尝试 GPT 渠道的开发者和科研探索者。 |
| 国外机构合作定制 | 与国外机构合作，根据实际使用需求定制渠道。 | 有科研、开发或长期使用需求的个人与团队，可咨询适用方案。 |
| 高质量渠道聚合 | 将不同来源的优质模型渠道汇聚到同一个入口，方便按需选择。 | 同时使用多个模型生态、希望减少到处寻找渠道的用户。 |

可用模型、价格与渠道权限，以控制台中对应渠道的实际说明为准。

## 个人与团队服务

- **联系支持与用户社区**：官网提供联系支持及加入社区入口，可咨询渠道适配、接入问题与服务安排。
- **机构合作定制**：可围绕实际需求咨询适用渠道，不必自行把不同来源的 API 分散配置到多个客户端。
- **开票服务**：官网明确支持开具发票。团队采购或报销前，向支持确认开票资料、办理方式及适用条件。
- **故障服务安排**：官网介绍了故障后的特色补偿安排；具体补偿方式和条件可通过官网联系支持确认。

## 在 uni-switch 中接入

1. 从 [蝶祈云官网](https://www.dieqiyun.top/) 进入控制台。
2. 创建或复制 API Key，并查看对应渠道给出的 **API 接入地址**。不要将官网首页或登录页当作 API 地址。
3. 打开 uni-switch，选择 Codex 或 Claude Code；Claude 再选择桌面端或 CLI。
4. 点击 **添加供应商**，填写 API 地址和 Key，点击 **添加并使用**。
5. 软件自动检测协议、同步可用模型、尝试查询余额，并在写入后提示重启。后续可以在其他目标中直接复用该供应商。

跨协议使用时保持 uni-switch 后台运行；余额查询结果按界面显示的「账户余额」「密钥额度」等范围理解。具体功能、设置和问题排查见 [完整使用教程](tutorial.md)。
