# API Key 分组

同一个供应商可以保存多个 API Key。每个 Key 可以设置分组名称，并获取该 Key 自己有权限访问的模型列表。

1. 添加供应商时填写 API Key 和「API Key 分组名称」，例如「普通组」。
2. 编辑已有供应商，在「API Key 分组」中点击「添加 API Key 分组」，填写另一个 Key 和分组名称，例如「高级组」。
3. 每个 Key 添加后会读取其模型目录。点击名称可重命名；模型按钮可调整该 Key 允许使用的模型，刷新模型会更新上游目录。
4. 在 Codex 或其他支持模型显示名称的客户端选择模型，例如 `GPT-6.1 Sol · 高级组 · 蝶祈云API`。同一个模型在两个分组中可分别选择。

分组模型仅使用对应的 Key。该 Key 限流、额度不足或请求失败时，错误会返回客户端，不会改用另一个分组或供应商。关闭、移除 Key 或上游移除模型后，相应分组条目不再可选，旧分组标识也不能借用其他 Key 发请求。重命名保留模型标识；替换 Key 后需要重新选择对应模型。

新建供应商自动启用分组显示。旧供应商在界面添加分组或重命名 Key 后启用；未操作的旧配置保持原有模型目录。旧会话使用的 `供应商ID/模型ID` 和裸模型 ID 继续按原有供应商 Key 轮换与回退规则工作。升级后重新选择带分组名的模型，并重新打开客户端以更新模型列表。

未填写分组名称时显示 `Key 1`、`Key 2` 等名称，不在模型名称或模型标识中写入 API Key。客户端仅接受模型 ID、没有显示名称字段时，使用稳定且不包含密钥的模型标识。分组显示优先于「隐藏供应商名称」，以便确定请求使用的凭据。

API Key 分组属于供应商内部的凭据选择，与已经移除的路由分组功能无关。
