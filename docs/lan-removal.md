# 局域网功能移除

本轮从源码删除局域网共享功能，保留现有界面风格。

删除范围：

- 局域网共享开关、IP／CIDR 白名单、共享地址和公网地址展示。
- 共享地址发现、网络监听和代理信任逻辑，以及相关管理 API 和 CLI 参数。
- 浏览器访问中的“局域网”选项、网关共享卡片和连接地址选择器。
- 只服务于上述能力的辅助代码、翻译和测试。

网关和浏览器管理页仅使用本机回环监听。非本机地址、转发请求及管理端口
上的推理请求拒绝访问，旧共享配置或有效密钥不能开启共享。

保留本机网关、客户端配置、本机浏览器管理、网页来源 CORS、本机命名密钥
的用量归因／限额，以及 Windows 本机 WSL 的专用适配器和密钥检查。
连接外部供应商是出站请求，不属于本机局域网共享，继续保留。

历史文件不主动删除；旧浏览器 `lan` 模式不会启动监听，也不会自动覆写文件。
旧默认密钥的兼容字段只用于本机客户端恢复，不再代表共享开关，也不能开放端口。
本机浏览器扩展连接独立的推理网关端口；命名密钥仍保持会话隔离、轮换和撤销。
实现边界和可复现命令见
[本机网络契约](../backend/docs/subsystems/local-only.md)，实测记录见
[源码整合验证记录](source-integration-qa.md)。
