## 自动识别

新增或编辑供应商继续复用两字段接入流程中的模型接口检测结果。旧供应商没有检测记录时，列表用数据库保存的密钥自动查询模型接口，识别协议、认证方式和实际接入地址。该查询不发送计费推理请求，不修改客户端文件，不覆盖已选模型及每模型上下文。检测中显示“检测中…”，失败显示“未确认”和“重新检测”；检测完成前不能点击“使用”。

协议依据接口响应的 schema 标记识别。OpenAI 兼容接口即使返回 Claude 模型，仍显示 OpenAI。模型查询不能证明所有推理和工具能力；返回通用模型列表或同时提供多协议的网关，可在编辑界面的高级设置覆盖协议。明确手动指定的连接不会被后台检测覆盖。

探测开始和结果保存均比较完整的供应商快照；检测期间的重命名、模型修改、密钥更改或删除使旧结果失效。列表缓存也比较完整快照，避免同一秒内更新被迟到结果覆盖。

## 开关行为

转换默认开启，旧数据保持自动接入行为。Codex、Claude 桌面端和 Claude CLI 分别保存偏好。

- 对未使用的供应商关闭开关，只保存该客户端偏好，“使用”按钮禁用。其他客户端照常使用。
- 对正在使用的供应商关闭开关，恢复该客户端接管前的 API 配置、停用该供应商，并移除该端转换快照；不影响其他端。客户端重启提示沿用现有配置版本检测机制。
- 重新开启只保存偏好，用户点击“使用”后才切换供应商和写入转换地址。
- 接口本身可直接接入时不显示开关，后端也拒绝无意义的转换设置。
- 当前配置有待应用修改或外部冲突时，先处理该配置，再调整转换开关。

关闭活动转换的偏好更新、客户端配置恢复和快照撤销在同一个可恢复事务中执行。文件被占用或写入失败，不会提交“已关闭”状态；后端在所有应用入口再次检查开关，不能通过 IPC 绕过。
